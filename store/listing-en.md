## Name

Baro QR — QR Code Generator & Reader

## Short description

Create QR codes for websites and links, copy or save QR images, and read QR codes from images. Everything stays on your device.

## Detailed description

Want to open a website on your phone? Baro QR turns the current page or any link into a QR code. It also reads the URL or text inside a QR image.

■ Create a QR code for the current page
Click the extension icon to see a QR code for the page you're viewing. Edit the URL to update the code, or choose “Current tab” to restore the original page URL.

■ Copy QR images and save PNG files
Use “Copy image” to paste a QR code into a chat or document. Save a 1024 × 1024 PNG with a white border, or copy just the URL.

■ Right-click a link to create its QR code
Right-click an HTTP/HTTPS link and select “Create QR code with Baro QR.” The code opens in a separate window, without visiting the link first.

■ Read QR codes from images
Choose or drag in an image, or paste a screenshot with Ctrl+V on Windows or ⌘V on macOS. Review and copy the decoded text, or open a supported website link yourself. Decoded links are never opened or executed automatically.

■ Everything is processed on your device
The extension processes the active page's URL and title, the link you select, URLs you enter, and images you provide in browser memory. It does not send them to a developer server or external QR service, and it does not keep a usage history. No account, advertisements, or analytics. Clipboard writes and downloads happen only when you use their controls.

■ English and Korean
The interface, context menu, and feedback messages follow your browser's display language. Korean is used for Korean browsers, and English for other languages.

■ Permissions
activeTab: temporarily reads the URL and title of the tab where you invoke the extension.
contextMenus: adds a QR action to the context menu for website links.

■ Supported formats and limits
For desktop Chrome on Windows and macOS. QR generation supports HTTP/HTTPS URLs. The image reader supports PNG, JPG, WebP, GIF, and BMP files up to 10 MB. It reads one QR code per image and uses the first frame of a GIF. If a code is small or blurry, crop to the QR code and try again. QR generation and image reading work offline; opening a website requires a network connection.
