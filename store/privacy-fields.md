# 개인정보 및 권한 입력란

바로 QR v1.1.1의 소스와 Manifest V3 권한을 기준으로 준비한 등록 초안입니다. 게시자는 최종 제출 전에 실제 입력란과 정책에 맞는지 검토해야 합니다.

## 단일 목적 — 복사용

웹사이트 주소를 QR코드로 공유하고, 사용자가 제공한 QR 이미지에서 주소나 텍스트를 읽는 도구입니다. 현재 탭·선택한 링크의 QR 생성, QR 이미지 복사·저장, 이미지 해석은 모두 이 QR 공유·읽기 목적을 위한 기능이며 브라우저 안에서 처리됩니다.

## activeTab 사용 이유 — 복사용

사용자가 도구 모음 아이콘 또는 링크 우클릭 메뉴를 실행한 탭의 URL과 제목을 일시적으로 읽어 현재 페이지의 QR코드를 만들고 출처를 표시합니다. 전체 사이트에 대한 지속적인 접근이나 방문 기록 조회 권한을 요청하지 않으며, 사용자의 동작 없이 탭을 감시하지 않습니다.

## contextMenus 사용 이유 — 복사용

HTTP/HTTPS 링크를 우클릭했을 때 「링크를 바로 QR로 만들기」 메뉴를 제공합니다. 사용자가 이 메뉴를 선택한 링크의 주소로만 별도 QR 창을 열며, 해당 링크에 자동으로 방문하거나 페이지 콘텐츠를 읽지 않습니다.

## 원격 코드

선택: No, I am not using remote code.

설명: QR 생성(qrcode)과 해석(jsQR) 라이브러리를 설치 ZIP에 포함합니다. 외부 스크립트·CDN·원격 WebAssembly·동적 코드 다운로드를 사용하지 않습니다. 이미지 해석용 Worker도 확장에 포함된 qr-reader.worker.js를 사용합니다. CSP는 네트워크 연결을 connect-src 'none'으로 제한합니다.

## 데이터 사용 신고

외부 서버로 전송하지 않는다는 사실만으로 「사용자 데이터를 전혀 처리하지 않는다」고 신고하지 않습니다. Chrome의 안내는 기기 내 처리도 공개하도록 요구합니다. 현재 구현은 다음 정보를 사용자 동작에 따라 일시적으로 처리합니다.

| 데이터 범주 | 현재 처리 내용 | 용도 / 보관 |
| --- | --- | --- |
| 웹 방문 정보 / Web history | 실행한 탭과 선택한 링크의 URL | QR 생성. 전체 방문 기록 API를 사용하지 않고 메모리에서만 처리 |
| 웹사이트 콘텐츠 / Website content | 탭 제목, 사용자가 직접 제공한 QR 이미지와 해석 내용 | 미리보기·QR 해석·결과 표시. 외부 전송이나 이력 저장 없음 |

위 두 범주를 현재 대시보드의 데이터 유형 정의와 대조해 신고합니다. 웹 방문 정보의 신고는 전체 방문 기록을 수집한다는 뜻이 아니며, URL에 접근하는 범위를 투명하게 밝히기 위한 것입니다. 사용자 제공 이미지·텍스트는 개인정보처리방침에도 별도로 명시합니다.

신원, 건강, 금융, 인증, 개인 통신, 위치 또는 사용자 행동 분석을 별도 기능으로 수집하지 않습니다. 임의의 URL·QR에는 사용자가 넣은 민감한 정보가 포함될 수 있으므로, 이를 개발자에게 보내지 않고 기능 처리에만 사용한다는 점을 함께 설명합니다.

제한적 사용 확인 사항:
- 사용자 데이터를 판매하거나 광고용으로 제공하지 않습니다.
- 명시한 QR 공유·읽기 목적과 무관하게 사용·전송하지 않습니다.
- 신용도 평가나 대출 판단에 사용·전송하지 않습니다.

이 확인 사항은 게시자가 실제 처리 방식과 일치하는지 검토한 후 직접 인증합니다.
